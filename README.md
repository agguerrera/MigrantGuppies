This work is currently under review at the American Naturalist.

Title: Geographic differences in color pattern and female interest provide an advantage for wild migrant male guppies (Poecilia reticulata)

Brief abstract: Understanding the maintenance of genetic variation in wild populations is challenging because the evolutionary processes that shape variation do not act independently. Negative frequency-dependent selection (NFDS), in which rare genotypes have a fitness advantage over common genotypes, can maintain high levels of heritable trait variation. One potential outcome of NFDS is an increase in the effective migration rate, as migrants often carry rare phenotypes that may be favored in new environments. The ecological mechanisms underlying a “rare migrant advantage” are largely unknown. Using Trinidadian guppies (Poecilia reticulata), we evaluated whether migrant males are likely to exhibit unfamiliar phenotypes and whether they gain behavioral advantages during post-dispersal mating interactions. We quantified geographic variation in whole-color patterns of 566 wild male guppies and paired these data with behavioral assays to measure female interest in migrant males with unfamiliar color patterns. Male color patterns differed over small geographic spatial scales, and females were more interested in migrant males compared to resident males. However, female interest did not increase with quantitative color pattern rarity. Our findings highlight a potential migrant-associated advantage consistent with NFDS, while revealing that the traits underlying this advantage may be more complex than quantitative color pattern rarity alone.

## REPRODUCING ANALYSES
All analyses were conducted in RStudio. The repository contains the R scripts, input datasets, and RStudio project file required to reproduce analyses and figures presented in the manuscript. 

### Getting started

1. Download the repository by selecting **Code → Download ZIP** on GitHub.
2. Extract the ZIP file to a local directory.
3. Open `MigrantGuppies.Rproj` in RStudio.
4. Install the required R packages listed at the beginning of the analysis scripts.
5. Each script can be run independently using the input files specified in its description below or within the scripts themselves. Scripts are numbered to reflect the general analytical workflow rather than a required execution order.

### Project structure

- `MigrantGuppies.Rproj`: RStudio project file.
- `README.md`: Repository documentation and instructions.
- `data/`: Input datasets used in the analyses.
- `scripts/`: R scripts for data processing, statistical analyses, and figure generation.
- `figures/`: Figures generated by the analysis scripts.

All file paths are specified relative to the project directory using the `here` package. Users should not need to modify file paths after opening the RStudio project.

### Code script description
1. 01_color_dapc_mantel.R
R script used to run Discriminant Analysis of Principal Components, PERMANOVAs, and Mantel tests. This code also calculates the proportion of orange and black coloration present on each male. Input files needed to run code: rgb_uv_pool5DT1PR.csv and xy5DT1PR.csv. 
    
3. 02_color_variance.R
R script used to compute color pattern variance in all three sampled tributaries based on the trace of the covariance matrix. Input file needed to run code: rgb_uv_pool5DT1PR.csv. 
    
3. 03_color_rarity_calculation.R
R script used to calculate trial- and pool-level rarity metrics. Trial rarity is calculated based on the Euclidean distance to the trial centroid (mean). Trial centroid includes color pattern vectors of all experimental males). Pool rarity is calculated based on the Euclidean distance to the mean focal pool centroid. Pool centroid includes color pattern vectors of all males found in natural pool, but excludes migrant males used in corresponding trials). Migrant male pool rarity scores are calculated separately by adding each individual migrant's color vector to the color matrix of the focal resident pool. This avoids migrant males tested with individuals from the same focal pool being included in the pool mean. Input files required: rgb_uv_pool5DT1PR.csv and pool_info.csv
        
4. 04_statistics.R
R script used to compute all statistics. Four models are assessed: (1) female interest model with categorical predictor of male type (resident common, resident rare, migrant unfamiliar), (2) female interest with categorical predictor of migrant status (migrant, resident) and continuous predictor of trial-level rarity metrics, (3) female interest with categorical predictor of migrant status (migrant, resident) and continuous predictor of pool-level rarity metrics, and (4) male-male competition model with categorical predictor of male type. Input files required: combined_rarity.csv, focal_behaviors.csv, annotated_behaviors.csv
